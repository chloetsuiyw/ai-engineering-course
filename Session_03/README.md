# Session 03 - Data Cleaning and Preprocessing

This package contains a 60-minute teaching session for UK working professionals with basic Python experience.

## Session scope

- **Session title:** Data Cleaning and Preprocessing
- **Key theory topics:** missing values, duplicates, outliers, categorical and numerical variables, scaling, encoding, reproducible notebooks
- **Practical activity:** clean a messy CSV and produce before/after dataset diagnostics
- **Tools:** Pandas, NumPy, Matplotlib/Seaborn, GitHub
- **Learning outcome:** prepare a dataset for modelling without destroying signal or introducing bias
